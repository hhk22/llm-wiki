# v3 초기 Wiki 생성 기록

2026-09-26, 고정 원본 120개에서 **본문 120개와 목차 5개**를 생성했다. 범위는 Wiki 구축이며, Wiki 기반 질의와 기존 RAG 대비 답변 품질·속도는 아직 측정하지 않았다.

## 생성 조건과 기록

| 항목 | 값 |
| --- | --- |
| 모델 | `gemini-3.5-flash-lite` |
| 생성 설정 | temperature 0, 페이지 5개씩, 호출 간 최소 16초 |
| 입력 | 대상 원본과 참조로 연결된 원본; 링크·목차는 전체 페이지 요약 |
| 제외한 입력 | 평가 질문·정답 |
| 완료 작업 | 페이지 24묶음, 관련 링크 4묶음, 목차 5개 = 33개 |
| 기록된 호출 | 66회: 검증 통과 33회, 출력 검증 실패 33회 |
| 보고된 토큰 합계 | 입력 343,238 / 출력 182,849 / 합계 526,087 |
| 기록된 API 호출 시간 합계 | 631.40초 |
| 구축 시작~완료 | 1,368.54초; 호출 간 대기와 작업 중단 포함 |

위 사용량은 **현재 manifest에 기록된 응답의 합계**다. 실패한 출력·재시도를 포함하며, 이전 모델 실험과 응답을 기록하지 못한 중단 호출은 제외한다. 전체 과금액이나 질문별 응답 성능으로 해석하지 않는다.

FAQ 생성에서 두 항목의 근거 누락이 번갈아 반복됐다. 마지막 오류만 전달하던 재시도를 수정해 이전 오류도 누적 전달한다. 코드 변경 전 완료한 20묶음은 원본·모델·정책·스키마와 프롬프트 일치를 확인하고 다시 검증해 재사용했다. 이전 코드 해시와 재사용 목록은 manifest의 `implementation_history`에 남겼다.

**원문 인용의 존재와 링크의 유효성은 설명의 정확성·완전성과 다르다.** 모든 페이지의 의미·인과관계를 전수 검토한 결과는 아니다. 일부 페이지는 원본 요약에 머물며, v30에는 규칙별 변경 이력을 직접 잇는 링크가 없다. 과거 페이지의 `현재 규칙` 절은 상단의 버전 시점과 함께 읽어야 하므로, 질의 구현 전 표현과 연결을 더 검토한다.

다음 단계는 현재 규칙·변경 이력·상충 내용 검토, Wiki 기반 질의 구현, 동일 조건의 답변 비교다. 기존 `vector`·`hybrid`·`keyword`와 답변 API는 유지했다.

원본 해시·모델·프롬프트·출력·호출 시각은 [manifest](../wiki/_build/manifest.json)와 [호출 기록](../wiki/_build/calls/)에, 기계 판독용 집계는 [검증 JSON](wiki-build-validation.json)에 보관한다. 재생성·재개 명령은 [README](../README.md#v3--원본으로-wiki-생성)에 있다.
