# 배포 가이드 v25

- 변경: 연말 배포 동결 기간을 정한다. 12월 22일부터 1월 2일까지 배포하지 않는다.

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 목요일 오후, 공휴일 전날, 12/22~1/2 연말 동결
- 승인자: 팀 리드 + 서비스 오너
