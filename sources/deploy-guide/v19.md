# 배포 가이드 v19

- 변경: 롤백은 승인 없이 배포자가 즉시 실행할 수 있다.
- 이유: 장애 리포트 #14 이후 결정

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 금요일 오후, 공휴일 전날
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v18
