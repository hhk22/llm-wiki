# 배포 가이드 v7

- 변경: 배포 승인자를 변경한다. 팀 리드와 SRE 온콜 두 명의 승인이 필요하다.
- 이유: 장애 리포트 #05 이후 결정

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v6
