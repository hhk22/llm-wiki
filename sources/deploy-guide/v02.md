# 배포 가이드 v2

- 변경: staging 배포 단계를 추가한다. prod 배포 전 staging에 먼저 배포한다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: 이전 빌드를 `deploy-prod`로 재실행
- 배포 금지 시간: 없음
- 승인자: 팀 리드
- 이전 버전: 배포 가이드 v1
