# 배포 가이드 v10

- 변경: 배포 시작·완료 알림을 Slack `#deploy` 채널로 자동 전송한다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v9
