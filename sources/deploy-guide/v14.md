# 배포 가이드 v14

- 변경: 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다.

## 현재 규칙
- 배포 도구: GitHub Actions (Jenkins 병행)
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>`
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v13
