# 배포 가이드 v3

- 변경: Jenkins 오류 수정 (E-012 빌드 캐시 손상). 빌드 전 캐시 삭제 단계를 추가한다.

## 현재 규칙
-  배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: 이전 빌드를`deploy-prod`로 재실행
- 배포 금지 시간: 없음
- 승인자: 팀 리드
- 이전 버전: 배포 가이드 v2
