# 배포 가이드 v4

- 변경: Jenkins 오류 수정 (E-017 배포 타임아웃). 타임아웃을 10분에서 20분으로 늘린다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: 이전 빌드를 `deploy-prod`로 재실행
- 배포 금지 시간: 없음
- 승인자: 팀 리드
- 이전 버전: 배포 가이드 v3
