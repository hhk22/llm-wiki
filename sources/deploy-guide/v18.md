# 배포 가이드 v18

- 변경: Jenkins를 완전히 종료한다. Jenkins 관련 절차는 더 이상 유효하지 않다.

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>`
- 배포 금지 시간: 금요일 오후, 공휴일 전날
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v17
