# 배포 가이드 v16

- 변경: 배포 금지 시간을 확대한다. 금요일 오후와 공휴일 전날에는 배포하지 않는다.

## 현재 규칙
- 배포 도구: GitHub Actions (Jenkins 병행)
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>`
- 배포 금지 시간: 금요일 오후, 공휴일 전날
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v15
