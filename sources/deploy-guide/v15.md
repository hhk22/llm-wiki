# 배포 가이드 v15

- 변경: GitHub Actions 오류 수정 (E-021 워크플로 권한 부족). 워크플로에 `deployments: write` 권한을 추가한다.
- 이유: 장애 리포트 #12 이후 결정

## 현재 규칙
- 배포 도구: GitHub Actions (Jenkins 병행)
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>`
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v14
