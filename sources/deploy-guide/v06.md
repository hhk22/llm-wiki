# 배포 가이드 v6

- 변경: 롤백 절차를 명문화한다. Jenkins job `rollback-prod`를 사용한다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드
- 이전 버전: 배포 가이드 v5
