# 배포 가이드 v23

- 변경: GitHub Actions 오류 수정 (E-025 동시 배포 충돌). 같은 서비스의 동시 배포를 잠금으로 막는다.
- 이유: 장애 리포트 #20 이후 결정

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 목요일 오후, 공휴일 전날
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v22
