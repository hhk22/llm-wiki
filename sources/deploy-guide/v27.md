# 배포 가이드 v27

- 변경: 배포 명령에 변경 티켓 번호를 필수로 붙인다.

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod --ticket <id>`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 목요일 오후, 공휴일 전날, 12/22~1/2 연말 동결
- 승인자: 팀 리드 + 서비스 오너
- 이전 버전: 배포 가이드 v26
