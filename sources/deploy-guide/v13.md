# 배포 가이드 v13

- 변경: 배포 전 readiness 헬스체크 통과를 필수로 한다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v12
