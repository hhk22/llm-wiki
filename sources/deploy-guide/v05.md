# 배포 가이드 v5

- 변경: 배포 금지 시간을 추가한다. 금요일 오후에는 prod 배포를 하지 않는다.
- 이유: 장애 리포트 #03 이후 결정

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: 이전 빌드를 `deploy-prod`로 재실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드
- 이전 버전: 배포 가이드 v4
