# 배포 가이드 v11

- 변경: Jenkins 오류 수정 (E-019 자격 증명 만료). 자격 증명을 90일마다 자동 갱신한다.

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v10
