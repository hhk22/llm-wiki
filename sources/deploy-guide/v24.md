# 배포 가이드 v24

- 변경: 배포 승인자를 변경한다. SRE 온콜 대신 서비스 오너가 승인한다.

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 목요일 오후, 공휴일 전날
- 승인자: 팀 리드 + 서비스 오너
- 이전 버전: 배포 가이드 v23
