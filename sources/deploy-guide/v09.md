# 배포 가이드 v9

- 변경: DB 마이그레이션은 배포와 분리한다. 배포 전에 별도 job으로 먼저 실행한다.
- 이유: 장애 리포트 #08 이후 결정

## 현재 규칙
- 배포 도구: Jenkins
- 배포 명령: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행
- 롤백 명령: Jenkins job `rollback-prod` 실행
- 배포 금지 시간: 금요일 오후
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v8
