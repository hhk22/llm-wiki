# 배포 가이드 v22

- 변경: 배포 금지 시간을 변경한다. 금요일 오후 대신 목요일 오후에 배포하지 않는다. 공휴일 전날은 유지한다.
- 이유: 장애 리포트 #18 이후 결정

## 현재 규칙
- 배포 도구: GitHub Actions
- 배포 명령: `deploy run --env prod`
- 롤백 명령: `deploy rollback --to <version>` (승인 불필요)
- 배포 금지 시간: 목요일 오후, 공휴일 전날
- 승인자: 팀 리드 + SRE 온콜
- 이전 버전: 배포 가이드 v21
