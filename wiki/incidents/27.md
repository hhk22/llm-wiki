# 장애 리포트 #27

관리자 API 권한 오류가 발생하여 잘못 배포된 역할 매핑 설정을 수정해 재배포했다. [1] [2]

## 장애 개요

- 2026-03-11에 api-gateway 서비스에서 SEV2 등급의 장애가 발생했다. [3] [4] [5]
- 관리자 API 호출이 전부 권한 오류를 반환했다. [6]

## 원인과 조치

- 역할 매핑 설정이 잘못 배포되어 에러 코드 E-006이 발생했다. [1]
- 설정을 수정하여 재배포했다. [2]
