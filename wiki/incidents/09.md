# 장애 리포트 #09

모든 API 응답이 지연된 장애 리포트입니다. [1]

## 개요 및 증상

- 날짜는 2025-05-21이고 서비스는 order-api, payment-api이며 등급은 SEV2이다. [2] [3] [4]
- 모든 API 응답이 10초 이상 걸렸다. [1]

## 원인 및 조치

- DB 커넥션 풀이 고갈되고 커넥션 반환 누락이 원인이며 (에러 코드 E-008) 커넥션 누수 코드를 수정하고 풀 크기를 늘렸다. [5] [6]
