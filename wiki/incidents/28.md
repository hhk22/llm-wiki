# 장애 리포트 #28

외부 발송 서비스 API 키 회수로 인한 주문 완료 알림 미발송 장애를 새 키 발급으로 조치했다. [1] [2]

## 장애 개요

- 2026-03-18에 notification-worker 서비스에서 SEV3 등급의 장애가 발생했다. [3] [4] [5]
- 주문 완료 알림이 발송되지 않았다. [6]

## 원인과 조치

- 외부 발송 서비스 API 키가 회수되어 에러 코드 E-010이 발생했다. [1]
- 새 키를 발급받아 교체했다. [2]
