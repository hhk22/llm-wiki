# 장애 목차

한국어 Wiki의 장애 리포트 목록을 주제별로 탐색하기 위한 목차입니다.

## 주문 및 결제 관련 장애

- [장애 리포트 #01](01.md) — 주문 생성 요청이 검증 규칙 오류로 인해 30% 실패하여 이전 빌드로 롤백하는 장애가 발생했다.
- [장애 리포트 #03](03.md) — 금요일 오후 환경 변수 누락 채 배포된 결제 API 장애로 인해 배포 가이드 v5에 배포 금지 시간이 추가되었다.
- [장애 리포트 #04](04.md) — 동시성 처리 부재로 상품 재고가 음수로 표시된 SEV3 등급 장애가 발생하여 단일 트랜잭션으로 변경되었다.
- [장애 리포트 #10](10.md) — 전체 배포 후 결제 타임아웃이 급증한 장애 리포트입니다.
- [장애 리포트 #14](14.md) — 검증 규칙 회귀 및 롤백 승인 대기로 인해 복구가 지연되는 장애가 발생했다.
- [장애 리포트 #19](19.md) — 카나리 10% 단계에서 오류율이 올라 배포가 자동 중단된 order-api 장애 리포트입니다.
- [장애 리포트 #24](24.md) — 원인 분석 부재로 인해 1월에 롤백했던 것과 동일한 주문 검증 오류 장애가 재발했다.
- [장애 리포트 #28](28.md) — 외부 발송 서비스 API 키 회수로 인한 주문 완료 알림 미발송 장애를 새 키 발급으로 조치했다.

## 인증 및 권한 관련 장애

- [장애 리포트 #02](02.md) — 잘못된 토큰 TTL 설정으로 사용자가 주기적으로 재로그인해야 했던 SEV3 등급 장애가 발생하여 수정 재배포되었다.
- [장애 리포트 #12](12.md) — GitHub Actions 전환 후 배포 권한 부족으로 배포가 중간에 실패하는 장애가 발생했다.
- [장애 리포트 #13](13.md) — 새 저장소의 워크플로 권한 설정 누락으로 카탈로그 API 배포가 연속 실패했다.
- [장애 리포트 #16](16.md) — 외부 요청이 전부 TLS 오류로 실패한 api-gateway 인증서 만료 장애 리포트입니다.
- [장애 리포트 #17](17.md) — 저장소 이전으로 권한이 초기화되어 긴급 수정 배포가 지연된 notification-worker 장애 리포트입니다.
- [장애 리포트 #27](27.md) — 관리자 API 권한 오류가 발생하여 잘못 배포된 역할 매핑 설정을 수정해 재배포했다.

## 배포 및 인프라 관련 장애

- [장애 리포트 #05](05.md) — 승인 단계 미강제로 승인되지 않은 변경이 배포되어 발생한 SEV2 등급 장애로 인해 배포 가이드 v7에 승인 절차가 반영되었다.
- [장애 리포트 #08](08.md) — 배포 중 서비스가 다운된 장애 리포트입니다.
- [장애 리포트 #15](15.md) — 메모리 누수가 헬스체크에서 드러나지 않아 배포 후 Pod가 반복 재시작되는 장애가 발생했다.
- [장애 리포트 #18](18.md) — 목요일 오후 주간 정산 배치 중 배포가 실행되어 정산이 실패한 settlement-pipeline 장애 리포트입니다.
- [장애 리포트 #20](20.md) — 두 명이 동시에 배포하여 서로 다른 버전이 섞인 payment-api 장애 리포트입니다.
- [장애 리포트 #21](21.md) — 대규모 리팩터링 배포 후 스키마 변경으로 롤백이 불가능한 SEV1 등급의 catalog-api 장애가 발생했다.
- [장애 리포트 #22](22.md) — Vault 정책 변경으로 시크릿 읽기가 거부되어 order-api와 user-api에서 SEV2 등급의 장애가 발생했다.
- [장애 리포트 #23](23.md) — 시크릿 누락으로 인해 user-api 서비스의 배포가 실패하는 SEV3 등급의 장애가 발생했다.
- [장애 리포트 #25](25.md) — 노드 리소스 부족으로 인해 admin-web 서비스의 새 Pod가 10분간 Pending 상태로 시작되지 않는 장애가 발생했다.
- [장애 리포트 #26](26.md) — 목요일 오후 배포 시도 중 배포 금지 시간 위반 에러 코드로 인해 차단되었다.
- [장애 리포트 #30](30.md) — readiness 경로 변경으로 인한 헬스체크 실패 자동 중단 장애를 경로 수정 후 재배포하여 조치했다.
