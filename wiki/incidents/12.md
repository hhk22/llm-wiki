# 장애 리포트 #12

GitHub Actions 전환 후 배포 권한 부족으로 배포가 중간에 실패하는 장애가 발생했다. [1]

## 장애 개요

- 2025년 7월 16일에 order-api 서비스에서 SEV2 등급의 장애가 발생했다. [2] [3] [4]
- GitHub Actions 전환 후 배포가 중간에 실패해 절반의 Pod만 새 버전인 증상이 나타났다. [1]

## 원인 및 조치

- 워크플로에 배포 권한이 없는 에러 코드 E-021 상황이 원인이 되었다. [5] [6]
- 권한을 추가하고 배포를 다시 실행하여 조치했다. [7]
- 이후 변경으로 후속 조치가 배포 가이드 v15에 반영되었다. [8]
