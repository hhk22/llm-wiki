# 배포 가이드 v17

> v17 시점 · 과거 버전

아티팩트 업로드 실패 오류(E-023)에 대응하기 위해 업로드 재시도가 3회로 설정되었다. [1] [2]

## 변경 사항 및 에러 대응

- GitHub Actions 아티팩트 업로드 실패(E-023) 오류를 수정하기 위해 업로드 재시도가 3회로 설정되었다. [1] [3] [2]
- 에러 코드 E-023의 대응은 재시도하는 것이며 배포 가이드 v17에서 3회 자동 재시도되었다. [4]

## 현재 규칙

- 배포 도구는 GitHub Actions이며 Jenkins를 병행 운영한다. [5]
- 배포 명령은 `deploy run --env prod`이며 롤백 명령은 `deploy rollback --to <version>`이다. [6] [7]
- 배포 금지 시간은 금요일 오후와 공휴일 전날이다. [8]
- 승인자는 팀 리드와 SRE 온콜이다. [9]
- 이전 버전은 배포 가이드 v16이다. [10]
