# 배포 가이드 v11

> v11 시점 · 과거 버전

현재 적용 기준은 [배포 가이드 v30](v30.md)에서 확인한다.

Jenkins 자격 증명 만료 오류 수정과 자동 갱신 도입을 반영한 배포 가이드 v11이다. [1]

## 변경 내용

- Jenkins 오류 수정 (E-019 자격 증명 만료)으로 자격 증명을 90일마다 자동 갱신한다. [1]

## v11 당시 규칙

- 배포 도구는 Jenkins를 사용한다. [2]
- 배포 명령은 Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행한다. [3]
- 롤백 명령은 Jenkins job `rollback-prod` 실행한다. [4]
- 배포 금지 시간은 금요일 오후이다. [5]
- 승인자는 팀 리드 + SRE 온콜이다. [6]
- 이전 버전은 배포 가이드 v10이다. [7]

## 규칙별 변경 이력

이 페이지의 버전까지 확인된 변경이다.

### 배포 명령

- v1 → v2: Jenkins job `deploy-prod` 실행 → Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 [8] [9]
  - staging 배포 단계를 추가한다. prod 배포 전 staging에 먼저 배포한다. [10]
  - [v2 변경 문서](v2.md)

### 배포 금지 시간

- v4 → v5: 없음 → 금요일 오후 [11] [12]
  - 배포 금지 시간을 추가한다. 금요일 오후에는 prod 배포를 하지 않는다. [13]
  - [v5 변경 문서](v5.md)
  - 장애 리포트 #03 이후 결정 [14]
  - [원인 사건: 장애 리포트 #03](../incidents/03.md)

### 롤백 명령

- v5 → v6: 이전 빌드를 `deploy-prod`로 재실행 → Jenkins job `rollback-prod` 실행 [15] [16]
  - 롤백 절차를 명문화한다. Jenkins job `rollback-prod`를 사용한다. [17]
  - [v6 변경 문서](v6.md)

### 승인자

- v6 → v7: 팀 리드 → 팀 리드 + SRE 온콜 [18] [19]
  - 배포 승인자를 변경한다. 팀 리드와 SRE 온콜 두 명의 승인이 필요하다. [20]
  - [v7 변경 문서](v7.md)
  - 장애 리포트 #05 이후 결정 [21]
  - [원인 사건: 장애 리포트 #05](../incidents/05.md)
