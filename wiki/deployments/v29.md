# 배포 가이드 v29

> v29 시점 · 과거 버전

롤백 후 48시간 안에 포스트모템을 작성해야 하는 규칙이 추가되었습니다. [1] [2]

## 변경 사유

- 이전 롤백 후 원인 분석을 하지 않아 같은 코드가 다시 배포되면서 order-api 서비스에 1월 장애가 재발한 이후 결정되었습니다. [3] [4]

## 대응 및 조치

- 롤백을 수행하고 롤백 후 포스트모템 작성을 의무화하였습니다. [5]

## 현재 규칙

- 배포 도구는 GitHub Actions를 사용합니다. [6]
- 배포 명령은 `deploy run --env prod --ticket <id>`를 사용합니다. [7]
- 롤백 명령은 `deploy rollback --to <version>`을 사용하며 승인이 불필요합니다. [8]
- 배포 금지 시간은 목요일 오후, 공휴일 전날, 12/22~1/2 연말 동결입니다. [9]
- 승인자는 팀 리드와 서비스 오너입니다. [10]
- 이전 버전은 배포 가이드 v28입니다. [11]
