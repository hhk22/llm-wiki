# 배포 가이드 v16

> v16 시점 · 과거 버전

배포 금지 시간이 금요일 오후와 공휴일 전날로 확대되었다. [1]

## 변경 사항 및 현재 규칙

- 금요일 오후와 공휴일 전날에는 배포가 금지된다. [1] [2]
- 배포 도구는 GitHub Actions를 사용하며 Jenkins를 병행 운영한다. [3]
- 배포 및 롤백 명령어는 각각 `deploy run --env prod`와 `deploy rollback --to <version>`을 사용한다. [4] [5]
- 승인자는 팀 리드와 SRE 온콜이다. [6]
- 이전 버전은 배포 가이드 v15이다. [7]
