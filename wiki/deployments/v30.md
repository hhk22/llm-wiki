# 배포 가이드 v30

> v30 시점 · 구축 원본 기준 최신

현재 규칙을 정리한 버전으로 추가적인 변경 사항은 없습니다. [1]

## 현재 규칙

- 배포 도구는 GitHub Actions를 사용합니다. [2]
- 배포 명령은 `deploy run --env prod --ticket <id>`를 사용합니다. [3]
- 롤백 명령은 `deploy rollback --to <version>`을 사용하며 승인이 불필요합니다. [4]
- 배포 금지 시간은 목요일 오후, 공휴일 전날, 12/22~1/2 연말 동결입니다. [5]
- 승인자는 팀 리드와 서비스 오너입니다. [6]
- 이전 버전은 배포 가이드 v29입니다. [7]
