# 배포 가이드 v15

> v15 시점 · 과거 버전

GitHub Actions 오류 수정 및 deployments: write 권한 추가를 반영한 배포 가이드 v15이다. [1] [2]

## 변경 내용 및 이유

- GitHub Actions 오류 수정 (E-021 워크플로 권한 부족)으로 워크플로에 `deployments: write` 권한을 추가한다. [1]
- 장애 리포트 #12 이후 결정되었다. [2] [3] [4]

## 현재 규칙

- 배포 도구는 GitHub Actions (Jenkins 병행)이다. [5]
- 배포 명령은 `deploy run --env prod`이다. [6]
- 롤백 명령은 `deploy rollback --to <version>`이다. [7]
- 배포 금지 시간은 금요일 오후이다. [8]
- 승인자는 팀 리드 + SRE 온콜이다. [9]
- 이전 버전은 배포 가이드 v14이다. [10]
