# 배포 가이드 v19

> v19 시점 · 과거 버전

현재 적용 기준은 [배포 가이드 v30](v30.md)에서 확인한다.

장애 리포트 #14 이후 롤백 승인 절차가 폐지되어 배포자가 즉시 롤백을 실행할 수 있게 되었다. [1] [2]

## 변경 이유 및 장애 배경

- 장애 리포트 #14 당시 order-api 서비스에 잘못된 검증 규칙이 배포되어(에러 코드 E-001) 주문 생성 요청의 장애가 발생했으나, 롤백에 SRE 승인이 필요해 복구가 40분 지연되었다. [3] [4] [5]
- 이에 대한 조치로 롤백 승인 절차를 폐지하였고 이는 배포 가이드 v19에 반영되었다. [6] [7]

## v19 당시 규칙

- 배포 도구는 GitHub Actions를 사용한다. [8]
- 배포 명령은 `deploy run --env prod`이며 롤백 명령은 `deploy rollback --to <version>`이고 승인이 불필요하다. [9] [10]
- 배포 금지 시간은 금요일 오후와 공휴일 전날이며, 승인자는 팀 리드와 SRE 온콜이고 이전 버전은 배포 가이드 v18이다. [11] [12] [13]

## 규칙별 변경 이력

이 페이지의 버전까지 확인된 변경이다.

### 배포 명령

- v1 → v2: Jenkins job `deploy-prod` 실행 → Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 [14] [15]
  - staging 배포 단계를 추가한다. prod 배포 전 staging에 먼저 배포한다. [16]
  - [v2 변경 문서](v2.md)
- v13 → v14: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 → `deploy run --env prod` [17] [18]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [19]
  - [v14 변경 문서](v14.md)

### 배포 금지 시간

- v4 → v5: 없음 → 금요일 오후 [20] [21]
  - 배포 금지 시간을 추가한다. 금요일 오후에는 prod 배포를 하지 않는다. [22]
  - [v5 변경 문서](v5.md)
  - 장애 리포트 #03 이후 결정 [23]
  - [원인 사건: 장애 리포트 #03](../incidents/03.md)
- v15 → v16: 금요일 오후 → 금요일 오후, 공휴일 전날 [24] [25]
  - 배포 금지 시간을 확대한다. 금요일 오후와 공휴일 전날에는 배포하지 않는다. [26]
  - [v16 변경 문서](v16.md)

### 롤백 명령

- v5 → v6: 이전 빌드를 `deploy-prod`로 재실행 → Jenkins job `rollback-prod` 실행 [27] [28]
  - 롤백 절차를 명문화한다. Jenkins job `rollback-prod`를 사용한다. [29]
  - [v6 변경 문서](v6.md)
- v13 → v14: Jenkins job `rollback-prod` 실행 → `deploy rollback --to <version>` [30] [31]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [19]
  - [v14 변경 문서](v14.md)
- v18 → v19: `deploy rollback --to <version>` → `deploy rollback --to <version>` (승인 불필요) [32] [10]
  - 롤백은 승인 없이 배포자가 즉시 실행할 수 있다. [1]
  - [v19 변경 문서](v19.md)
  - 장애 리포트 #14 이후 결정 [2]
  - [원인 사건: 장애 리포트 #14](../incidents/14.md)

### 승인자

- v6 → v7: 팀 리드 → 팀 리드 + SRE 온콜 [33] [34]
  - 배포 승인자를 변경한다. 팀 리드와 SRE 온콜 두 명의 승인이 필요하다. [35]
  - [v7 변경 문서](v7.md)
  - 장애 리포트 #05 이후 결정 [36]
  - [원인 사건: 장애 리포트 #05](../incidents/05.md)

### 배포 도구

- v13 → v14: Jenkins → GitHub Actions (Jenkins 병행) [37] [38]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [19]
  - [v14 변경 문서](v14.md)
- v17 → v18: GitHub Actions (Jenkins 병행) → GitHub Actions [39] [40]
  - Jenkins를 완전히 종료한다. Jenkins 관련 절차는 더 이상 유효하지 않다. [41]
  - [v18 변경 문서](v18.md)
