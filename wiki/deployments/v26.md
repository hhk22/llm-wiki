# 배포 가이드 v26

> v26 시점 · 과거 버전

feature flag 없는 대규모 변경 배포를 금지하도록 규칙이 변경되었습니다. [1] [2]

## 변경 사유

- DB 스키마가 함께 바뀌어 이전 버전이 동작하지 않아 catalog-api 서비스에 SEV1 장애가 발생한 이후 결정되었습니다. [3] [4]

## 대응 및 조치

- 핫픽스로 복구하고 feature flag 없는 대규모 변경을 금지하는 조치가 취해졌습니다. [5]

## 현재 규칙

- 배포 도구는 GitHub Actions를 사용합니다. [6]
- 배포 명령은 `deploy run --env prod`를 사용합니다. [7]
- 롤백 명령은 `deploy rollback --to <version>`을 사용하며 승인이 불필요합니다. [8]
- 배포 금지 시간은 목요일 오후, 공휴일 전날, 12/22~1/2 연말 동결입니다. [9]
- 승인자는 팀 리드와 서비스 오너입니다. [10]
- 이전 버전은 배포 가이드 v25입니다. [11]
