# 배포 가이드 v2

> v2 시점 · 과거 버전

현재 적용 기준은 [배포 가이드 v30](v30.md)에서 확인한다.

prod 배포 전에 staging 배포 단계를 추가한 배포 가이드 v2 규칙이다. [1]

## v2 당시 규칙

- 배포 도구는 Jenkins를 사용한다. [2]
- 배포 명령은 Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행한다. [3]
- 롤백 명령은 이전 빌드를 `deploy-prod`로 재실행하는 것이다. [4]
- 배포 금지 시간은 없다. [5]
- 승인자는 팀 리드이다. [6]

## 규칙별 변경 이력

이 페이지의 버전까지 확인된 변경이다.

### 배포 명령

- v1 → v2: Jenkins job `deploy-prod` 실행 → Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 [7] [3]
  - staging 배포 단계를 추가한다. prod 배포 전 staging에 먼저 배포한다. [1]
  - [v2 변경 문서](v2.md)
