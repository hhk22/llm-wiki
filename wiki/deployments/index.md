# 배포 목차

배포 가이드 버전별 문서 탐색 가이드

**구축 원본 기준 최신:** [배포 가이드 v30](v30.md)

## 초기 배포 가이드 (v1 - v10)

- [배포 가이드 v1](v1.md) — Jenkins를 사용하여 프로덕션 배포를 시작하는 초기 배포 가이드 v1 규칙이다.
- [배포 가이드 v2](v2.md) — prod 배포 전에 staging 배포 단계를 추가한 배포 가이드 v2 규칙이다.
- [배포 가이드 v3](v3.md) — 빌드 전 캐시 삭제 단계를 추가하여 Jenkins 빌드 캐시 손상 오류를 수정한 배포 가이드 v3 규칙이다.
- [배포 가이드 v4](v4.md) — 배포 타임아웃 오류 수정으로 제한 시간을 20분으로 늘린 배포 가이드 v4 규칙이다.
- [배포 가이드 v5](v5.md) — 장애 리포트 #03을 반영하여 금요일 오후 prod 배포 금지 시간을 추가한 배포 가이드 v5 규칙이다.
- [배포 가이드 v6](v6.md) — 배포 가이드 v6는 Jenkins job rollback-prod를 사용하는 롤백 절차를 명문화했습니다.
- [배포 가이드 v7](v7.md) — 장애 리포트 #05에 따라 배포 승인자가 팀 리드와 SRE 온콜 두 명으로 변경되었습니다.
- [배포 가이드 v8](v8.md) — 장애 리포트 #06에 따라 이미지 태그 형식을 service:git-sha로 제한하고 latest 태그를 금지했습니다.
- [배포 가이드 v9](v9.md) — 장애 리포트 #08에 따라 DB 마이그레이션을 배포와 분리하여 별도 job으로 먼저 실행하도록 변경되었습니다.
- [배포 가이드 v10](v10.md) — 배포 가이드 v10은 Slack #deploy 채널로 배포 시작 및 완료 알림을 자동 전송하도록 변경했습니다.

## 중기 배포 가이드 및 도구 전환 (v11 - v20)

- [배포 가이드 v11](v11.md) — Jenkins 자격 증명 만료 오류 수정과 자동 갱신 도입을 반영한 배포 가이드 v11이다.
- [배포 가이드 v12](v12.md) — 장애 리포트 10 이후 결정에 따라 payment-api 배포 시 카나리 10% 도입을 반영한 배포 가이드 v12이다.
- [배포 가이드 v13](v13.md) — 배포 전 readiness 헬스체크 통과 필수를 반영한 배포 가이드 v13이다.
- [배포 가이드 v14](v14.md) — 배포 도구를 GitHub Actions로 전환하고 Jenkins를 병행 운영하는 배포 가이드 v14이다.
- [배포 가이드 v15](v15.md) — GitHub Actions 오류 수정 및 deployments: write 권한 추가를 반영한 배포 가이드 v15이다.
- [배포 가이드 v16](v16.md) — 배포 금지 시간이 금요일 오후와 공휴일 전날로 확대되었다.
- [배포 가이드 v17](v17.md) — 아티팩트 업로드 실패 오류(E-023)에 대응하기 위해 업로드 재시도가 3회로 설정되었다.
- [배포 가이드 v18](v18.md) — Jenkins가 완전히 종료되어 관련 절차가 더 이상 유효하지 않게 되었다.
- [배포 가이드 v19](v19.md) — 장애 리포트 #14 이후 롤백 승인 절차가 폐지되어 배포자가 즉시 롤백을 실행할 수 있게 되었다.
- [배포 가이드 v20](v20.md) — 장애 리포트 #15 이후 배포 후 15분 동안 대시보드 모니터링이 의무화되었다.

## 최신 배포 가이드 및 규칙 강화 (v21 - v30)

- [배포 가이드 v21](v21.md) — 카나리 배포가 모든 서비스로 확대되어 10퍼센트에서 50퍼센트를 거쳐 100퍼센트 순서로 진행하도록 변경되었다.
- [배포 가이드 v22](v22.md) — 장애 리포트 #18 이후 목요일 오후 주간 정산 배치와의 충돌을 막기 위해 배포 금지 시간이 금요일 오후에서 목요일 오후로 변경되었다.
- [배포 가이드 v23](v23.md) — 장애 리포트 #20의 동시 배포 충돌 문제 이후 동일 서비스의 동시 배포를 잠금으로 막도록 규칙이 변경되었다.
- [배포 가이드 v24](v24.md) — 배포 승인자가 SRE 온콜에서 서비스 오너로 변경되었다.
- [배포 가이드 v25](v25.md) — 12월 22일부터 1월 2일까지의 연말 배포 동결 기간이 새롭게 지정되었다.
- [배포 가이드 v26](v26.md) — feature flag 없는 대규모 변경 배포를 금지하도록 규칙이 변경되었습니다.
- [배포 가이드 v27](v27.md) — 배포 명령에 변경 티켓 번호를 필수로 붙이도록 규칙이 변경되었습니다.
- [배포 가이드 v28](v28.md) — 시크릿 누락 오류를 수정하기 위해 배포 전 필수 시크릿 존재 검사가 추가되었습니다.
- [배포 가이드 v29](v29.md) — 롤백 후 48시간 안에 포스트모템을 작성해야 하는 규칙이 추가되었습니다.
- [배포 가이드 v30](v30.md) — 현재 규칙을 정리한 버전으로 추가적인 변경 사항은 없습니다.
