# 배포 가이드 v23

> v23 시점 · 과거 버전

장애 리포트 #20의 동시 배포 충돌 문제 이후 동일 서비스의 동시 배포를 잠금으로 막도록 규칙이 변경되었다. [1] [2]

## 변경 및 이유

- GitHub Actions 오류 수정으로 E-025 동시 배포 충돌을 막기 위해 같은 서비스의 동시 배포를 잠금으로 막는다. [1]
- 두 명이 동시에 배포해 버전이 섞인 장애 리포트 #20 이후 결정되었다. [2] [3]

## 현재 규칙

- 배포 도구는 GitHub Actions이다. [4]
- 배포 명령은 `deploy run --env prod`이다. [5]
- 롤백 명령은 `deploy rollback --to <version>`이며 승인이 불필요하다. [6]
- 배포 금지 시간은 목요일 오후와 공휴일 전날이다. [7]
- 승인자는 팀 리드와 SRE 온콜이다. [8]
- 이전 버전은 배포 가이드 v22이다. [9]
