# 배포 가이드 v24

> v24 시점 · 과거 버전

배포 승인자가 SRE 온콜에서 서비스 오너로 변경되었다. [1]

## 변경 사항

- 배포 승인자를 변경하여 SRE 온콜 대신 서비스 오너가 승인한다. [1]

## 현재 규칙

- 배포 도구는 GitHub Actions이다. [2]
- 배포 명령은 `deploy run --env prod`이다. [3]
- 롤백 명령은 `deploy rollback --to <version>`이며 승인이 불필요하다. [4]
- 배포 금지 시간은 목요일 오후와 공휴일 전날이다. [5]
- 승인자는 팀 리드와 서비스 오너이다. [6]
- 이전 버전은 배포 가이드 v23이다. [7]
