# 배포 가이드 v22

> v22 시점 · 과거 버전

장애 리포트 #18 이후 목요일 오후 주간 정산 배치와의 충돌을 막기 위해 배포 금지 시간이 금요일 오후에서 목요일 오후로 변경되었다. [1] [2]

## 변경 및 이유

- 금요일 오후 대신 목요일 오후에 배포하지 않도록 배포 금지 시간이 변경되었고 공휴일 전날은 유지된다. [1]
- 목요일 오후 주간 정산 배치 중 배포가 실행되어 정산이 실패한 장애 리포트 #18 이후 결정되었다. [2] [3]

## 현재 규칙

- 배포 도구는 GitHub Actions이다. [4]
- 배포 명령은 `deploy run --env prod`이다. [5]
- 롤백 명령은 `deploy rollback --to <version>`이며 승인이 불필요하다. [6]
- 배포 금지 시간은 목요일 오후와 공휴일 전날이다. [7]
- 승인자는 팀 리드와 SRE 온콜이다. [8]
- 이전 버전은 배포 가이드 v21이다. [9]
