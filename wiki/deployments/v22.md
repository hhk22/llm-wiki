# 배포 가이드 v22

> v22 시점 · 과거 버전

현재 적용 기준은 [배포 가이드 v30](v30.md)에서 확인한다.

장애 리포트 #18 이후 목요일 오후 주간 정산 배치와의 충돌을 막기 위해 배포 금지 시간이 금요일 오후에서 목요일 오후로 변경되었다. [1] [2]

## 변경 및 이유

- 금요일 오후 대신 목요일 오후에 배포하지 않도록 배포 금지 시간이 변경되었고 공휴일 전날은 유지된다. [1]
- 목요일 오후 주간 정산 배치 중 배포가 실행되어 정산이 실패한 장애 리포트 #18 이후 결정되었다. [2] [3]

## v22 당시 규칙

- 배포 도구는 GitHub Actions이다. [4]
- 배포 명령은 `deploy run --env prod`이다. [5]
- 롤백 명령은 `deploy rollback --to <version>`이며 승인이 불필요하다. [6]
- 배포 금지 시간은 목요일 오후와 공휴일 전날이다. [7]
- 승인자는 팀 리드와 SRE 온콜이다. [8]
- 이전 버전은 배포 가이드 v21이다. [9]

## 규칙별 변경 이력

이 페이지의 버전까지 확인된 변경이다.

### 배포 명령

- v1 → v2: Jenkins job `deploy-prod` 실행 → Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 [10] [11]
  - staging 배포 단계를 추가한다. prod 배포 전 staging에 먼저 배포한다. [12]
  - [v2 변경 문서](v2.md)
- v13 → v14: Jenkins job `deploy-staging` → `deploy-prod` 순서로 실행 → `deploy run --env prod` [13] [14]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [15]
  - [v14 변경 문서](v14.md)

### 배포 금지 시간

- v4 → v5: 없음 → 금요일 오후 [16] [17]
  - 배포 금지 시간을 추가한다. 금요일 오후에는 prod 배포를 하지 않는다. [18]
  - [v5 변경 문서](v5.md)
  - 장애 리포트 #03 이후 결정 [19]
  - [원인 사건: 장애 리포트 #03](../incidents/03.md)
- v15 → v16: 금요일 오후 → 금요일 오후, 공휴일 전날 [20] [21]
  - 배포 금지 시간을 확대한다. 금요일 오후와 공휴일 전날에는 배포하지 않는다. [22]
  - [v16 변경 문서](v16.md)
- v21 → v22: 금요일 오후, 공휴일 전날 → 목요일 오후, 공휴일 전날 [23] [7]
  - 배포 금지 시간을 변경한다. 금요일 오후 대신 목요일 오후에 배포하지 않는다. 공휴일 전날은 유지한다. [1]
  - [v22 변경 문서](v22.md)
  - 장애 리포트 #18 이후 결정 [2]
  - [원인 사건: 장애 리포트 #18](../incidents/18.md)

### 롤백 명령

- v5 → v6: 이전 빌드를 `deploy-prod`로 재실행 → Jenkins job `rollback-prod` 실행 [24] [25]
  - 롤백 절차를 명문화한다. Jenkins job `rollback-prod`를 사용한다. [26]
  - [v6 변경 문서](v6.md)
- v13 → v14: Jenkins job `rollback-prod` 실행 → `deploy rollback --to <version>` [27] [28]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [15]
  - [v14 변경 문서](v14.md)
- v18 → v19: `deploy rollback --to <version>` → `deploy rollback --to <version>` (승인 불필요) [29] [30]
  - 롤백은 승인 없이 배포자가 즉시 실행할 수 있다. [31]
  - [v19 변경 문서](v19.md)
  - 장애 리포트 #14 이후 결정 [32]
  - [원인 사건: 장애 리포트 #14](../incidents/14.md)

### 승인자

- v6 → v7: 팀 리드 → 팀 리드 + SRE 온콜 [33] [34]
  - 배포 승인자를 변경한다. 팀 리드와 SRE 온콜 두 명의 승인이 필요하다. [35]
  - [v7 변경 문서](v7.md)
  - 장애 리포트 #05 이후 결정 [36]
  - [원인 사건: 장애 리포트 #05](../incidents/05.md)

### 배포 도구

- v13 → v14: Jenkins → GitHub Actions (Jenkins 병행) [37] [38]
  - 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [15]
  - [v14 변경 문서](v14.md)
- v17 → v18: GitHub Actions (Jenkins 병행) → GitHub Actions [39] [40]
  - Jenkins를 완전히 종료한다. Jenkins 관련 절차는 더 이상 유효하지 않다. [41]
  - [v18 변경 문서](v18.md)
