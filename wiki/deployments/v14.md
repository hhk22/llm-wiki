# 배포 가이드 v14

> v14 시점 · 과거 버전

배포 도구를 GitHub Actions로 전환하고 Jenkins를 병행 운영하는 배포 가이드 v14이다. [1]

## 변경 내용

- 배포 도구를 GitHub Actions로 전환한다. Jenkins는 병행 운영한다. [1]

## 현재 규칙

- 배포 도구는 GitHub Actions (Jenkins 병행)이다. [2]
- 배포 명령은 `deploy run --env prod`이다. [3]
- 롤백 명령은 `deploy rollback --to <version>`이다. [4]
- 배포 금지 시간은 금요일 오후이다. [5]
- 승인자는 팀 리드 + SRE 온콜이다. [6]
- 이전 버전은 배포 가이드 v13이다. [7]
