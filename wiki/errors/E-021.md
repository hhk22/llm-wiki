# 에러 코드 E-021 워크플로 권한 부족

에러 코드 E-021은 배포 과정에서 워크플로에 필요한 권한이 없을 때 발생한다. [1] [2]

## 발생 원인과 대응

- 저장소 생성이나 이전 과정에서 deployments: write 권한이 누락되어 발생하며 설정 확인이 필요하다. [3] [4]

## 관련 장애 사례

- 이 에러는 장애 리포트 12번, 13번, 17번과 연관이 있다. [5]
- 장애 리포트 12번에서는 GitHub Actions 전환 후 배포가 중간에 실패하여 절반의 Pod만 새 버전이 되었고 워크플로에 배포 권한이 없어 발생했다. [6] [7]
- 장애 리포트 13번에서는 새 저장소에 워크플로 권한 설정이 누락되어 배포가 세 번 연속 실패하는 원인이 되었다. [8] [9]
- 장애 리포트 17번에서는 저장소 이전 과정에서 권한이 초기화되어 긴급 수정 배포가 1시간 지연되었다. [10] [11]

- [장애 리포트 #13](../incidents/13.md) — 새 저장소 워크플로 권한 설정 누락으로 카탈로그 API 배포가 연속 실패했습니다.
- [장애 리포트 #17](../incidents/17.md) — 저장소 이전으로 권한이 초기화되어 긴급 수정 배포가 지연되었습니다.
