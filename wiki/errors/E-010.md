# 에러 코드 E-010 알림 발송 실패

외부 발송 서비스 호출이 실패할 때 발생하는 에러 코드 E-010의 정보와 관련 장애 내용입니다. [1]

## 발생 위치 및 의미

- 발생 위치는 notification-worker이며 의미는 외부 발송 서비스 호출이 실패했다는 것이다. [2] [1]

## 원인 및 대응

- API 키 만료·회수, 외부 서비스 장애가 원인이며 API 키 상태를 확인해야 한다. [3] [4]
- 관련 장애는 장애 리포트 #28이다. [5]
- 주문 완료 알림이 발송되지 않은 증상이 있었으며 외부 발송 서비스 API 키가 회수된 것이 원인이었다. [6] [7]
- 새 키를 발급받아 교체하는 조치를 취했다. [8]
