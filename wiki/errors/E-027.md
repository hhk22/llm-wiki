# 에러 코드 E-027 시크릿 누락

에러 코드 E-027은 새 기능의 시크릿이 Vault에 미등록되어 배포 시 시크릿이 누락되었을 때 발생한다. [1] [2]

## 발생 정보

- 에러 코드 E-027은 배포 위치에서 발생한다. [3]
- 필요한 시크릿이 Vault에 없음을 의미한다. [1]

## 원인과 관련 장애

- 원인은 새 기능의 시크릿 미등록이다. [2]
- 관련 장애는 장애 리포트 #23이다. [4]
- 장애 리포트 #23의 날짜는 2026-01-28이며 user-api 서비스에서 SEV3 등급으로 발생했다. [5] [6] [7]
- 장애 리포트 #23의 증상은 배포가 시크릿 누락으로 실패한 것이며 원인은 새 기능에 필요한 시크릿이 Vault에 등록되지 않은 것이고 조치는 시크릿을 등록하고 배포 전 시크릿 검사를 추가한 것이다. [8] [9] [10]

## 대응 방법

- 대응 방법은 시크릿을 등록하는 것이며 배포 가이드 v28에서 배포 전 검사가 추가되었다. [11]
