# 오류 코드 목차

에러 코드 및 관련 장애에 대한 탐색 가이드입니다.

## API 및 인프라 에러

- [에러 코드 E-001 주문 검증 실패](E-001.md) — 주문 검증 실패 에러 코드 E-001은 order-api에서 발생하며 필수 항목 누락이나 잘못된 검증 규칙 배포가 원인이다.
- [에러 코드 E-002 재고 부족](E-002.md) — 재고 부족 에러 코드 E-002는 catalog-api에서 발생하며 요청 수량이 재고보다 많을 때 일어난다.
- [에러 코드 E-003 결제 승인 거절](E-003.md) — 결제 승인 거절 에러 코드 E-003은 payment-api에서 발생하며 PG사가 결제를 거절했음을 의미한다.
- [에러 코드 E-004 결제 타임아웃](E-004.md) — 결제 타임아웃 에러 코드 E-004는 payment-api에서 발생하며 PG사 응답 지연이 원인이다.
- [에러 코드 E-005 인증 토큰 만료](E-005.md) — 인증 토큰 만료 에러 코드 E-005는 api-gateway에서 발생하며 액세스 토큰의 유효 기간이 지난 것이다.
- [에러 코드 E-006 권한 없음](E-006.md) — 사용자 역할에 API 권한이 없을 때 발생하는 에러 코드 E-006의 원인과 대응 방법입니다.
- [에러 코드 E-007 요청 한도 초과](E-007.md) — rate limit을 초과했을 때 발생하는 에러 코드 E-007의 정보와 관련 장애 내용입니다.
- [에러 코드 E-008 DB 커넥션 고갈](E-008.md) — 커넥션 풀에서 연결을 얻지 못할 때 발생하는 에러 코드 E-008의 원인과 관련 장애 내역입니다.
- [에러 코드 E-009 Kafka 발행 실패](E-009.md) — 이벤트를 브로커에 발행하지 못할 때 발생하는 에러 코드 E-009의 원인과 관련 장애 내역입니다.
- [에러 코드 E-010 알림 발송 실패](E-010.md) — 외부 발송 서비스 호출이 실패할 때 발생하는 에러 코드 E-010의 정보와 관련 장애 내용입니다.

## 빌드 및 배포 에러

- [에러 코드 E-011 빌드 실패: 테스트](E-011.md) — 에러 코드 E-011은 테스트 단계에서의 빌드 중단과 실패를 의미한다.
- [에러 코드 E-012 빌드 캐시 손상](E-012.md) — 에러 코드 E-012는 손상된 캐시로 인한 빌드 실패를 다룬다.
- [에러 코드 E-013 이미지 푸시 실패](E-013.md) — 에러 코드 E-013은 레지스트리 인증 만료 또는 용량 초과로 인한 이미지 푸시 실패를 설명한다.
- [에러 코드 E-014 이미지 태그 없음](E-014.md) — 에러 코드 E-014는 태그 규칙 위반이나 latest 사용으로 인한 이미지 태그 없음 오류와 장애 리포트 #06을 다룬다.
- [에러 코드 E-015 헬스체크 실패](E-015.md) — 에러 코드 E-015는 readiness 헬스체크 실패를 의미하며 장애 리포트 #15 및 #30과 연관되어 있다.
- [에러 코드 E-016 설정 누락](E-016.md) — 에러 코드 E-016은 필수 환경 변수 누락으로 발생하는 배포 오류이며, 장애 리포트 #03의 원인이 되었다.
- [에러 코드 E-017 배포 타임아웃](E-017.md) — 에러 코드 E-017은 배포 제한 시간 초과로 발생하며, 배포 가이드 v4에서 타임아웃이 20분으로 늘어났다.
- [에러 코드 E-018 마이그레이션 실패](E-018.md) — 에러 코드 E-018은 DB 마이그레이션 실패를 의미하며 장애 리포트 #08의 원인이 되었다.
- [에러 코드 E-019 자격 증명 만료](E-019.md) — 에러 코드 E-019는 Jenkins 자격 증명 만료로 발생하며 배포 가이드 v11에서 자동 갱신되도록 수정되었다.
- [에러 코드 E-020 롤백 대상 없음](E-020.md) — 에러 코드 E-020은 롤백 대상 없음이나 호환성 문제로 발생하며 장애 리포트 #21과 연관된다.

## 권한 및 보안 에러

- [에러 코드 E-021 워크플로 권한 부족](E-021.md) — 에러 코드 E-021은 배포 과정에서 워크플로에 필요한 권한이 없을 때 발생한다.
- [에러 코드 E-022 승인 누락](E-022.md) — 에러 코드 E-022는 필요한 승인 단계가 강제되지 않아 승인 없이 배포가 실행되었을 때 발생한다.
- [에러 코드 E-023 아티팩트 업로드 실패](E-023.md) — 에러 코드 E-023은 일시적 네트워크 오류로 인해 빌드 결과물 업로드가 실패할 때 발생한다.
- [에러 코드 E-024 카나리 지표 이상](E-024.md) — 에러 코드 E-024는 카나리 단계에서 새 버전 결함으로 오류율이 기준을 초과해 배포가 자동 중단될 때 발생한다.
- [에러 코드 E-025 동시 배포 충돌](E-025.md) — 에러 코드 E-025는 배포 잠금이 없어 같은 서비스에 두 배포가 동시에 실행될 때 발생한다.
- [에러 코드 E-026 시크릿 접근 거부](E-026.md) — 에러 코드 E-026은 Vault 정책 변경이나 역할 매핑 오류로 인해 서비스가 시크릿을 읽지 못할 때 발생한다.
- [에러 코드 E-027 시크릿 누락](E-027.md) — 에러 코드 E-027은 새 기능의 시크릿이 Vault에 미등록되어 배포 시 시크릿이 누락되었을 때 발생한다.
- [에러 코드 E-028 노드 리소스 부족](E-028.md) — 에러 코드 E-028은 노드의 CPU 및 메모리 부족으로 인해 Pod가 스케줄되지 못하고 Pending 상태가 될 때 발생한다.
- [에러 코드 E-029 인증서 만료](E-029.md) — 에러 코드 E-029는 갱신 누락으로 인해 TLS 인증서가 만료될 때 발생한다.
- [에러 코드 E-030 배포 금지 시간 위반](E-030.md) — 에러 코드 E-030은 배포 가이드 최신 버전의 금지 시간을 미확인하여 배포 금지 시간에 배포를 시도할 때 발생한다.
