# 에러 코드 E-006 권한 없음

사용자 역할에 API 권한이 없을 때 발생하는 에러 코드 E-006의 원인과 대응 방법입니다. [1]

## 발생 위치 및 의미

- 에러 발생 위치는 api-gateway이며 의미는 사용자 역할에 해당 API 권한이 없는 것이다. [2] [1]

## 원인 및 대응

- 역할 매핑 누락 또는 잘못된 매핑 배포가 원인이며 역할 매핑 설정을 확인해야 한다. [3] [4]
- 관련 장애는 장애 리포트 #27이다. [5]
- 관리자 API 호출이 전부 권한 오류를 반환한 증상이 있었으며 역할 매핑 설정이 잘못 배포된 것이 원인이었다. [6] [7]
- 설정을 수정해 재배포하는 조치를 취했다. [8]
