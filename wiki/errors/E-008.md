# 에러 코드 E-008 DB 커넥션 고갈

커넥션 풀에서 연결을 얻지 못할 때 발생하는 에러 코드 E-008의 원인과 관련 장애 내역입니다. [1]

## 발생 위치 및 의미

- 발생 위치는 공통이며 의미는 커넥션 풀에서 연결을 얻지 못했다는 것이다. [2] [1]

## 원인 및 대응

- 커넥션 반환 누락, 풀 크기 부족, 느린 쿼리가 원인이며 풀 사용량과 반환 누락 코드를 확인해야 한다. [3] [4]
- 관련 장애는 장애 리포트 #09, #29이다. [5]
- 모든 API 응답이 10초 이상 걸린 장애 #09와 정산 배치가 DB 연결 실패로 중단된 장애 #29가 발생했다. [6] [7]
- 장애 #09는 커넥션 반환 누락이 원인으로 커넥션 누수 코드를 수정하고 풀 크기를 늘렸으며, 장애 #29는 배치가 커넥션을 반환하지 않고 종료된 것이 원인으로 커넥션 반환을 수정하고 배치를 재실행했다. [8] [9] [10] [11]

## 관련 Wiki

- [장애 리포트 #09](../incidents/09.md) — 모든 API 응답이 지연되는 DB 연결 실패 장애가 발생했습니다.
- [장애 리포트 #29](../incidents/29.md) — 배치 커넥션 미반환으로 DB 연결 실패 정산 중단 장애가 발생했습니다.
