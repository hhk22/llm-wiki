# 온보딩 FAQ Q16 첫 PR을 올릴 때 규칙이 있나요?

첫 PR 등록 시 리뷰어 승인과 티켓 번호 명시 규칙이 안내된다. [1]

## 규칙

- 첫 PR 등록 시 리뷰어 2명의 승인이 필요하고 변경 티켓 번호를 PR 제목에 붙인다. [1]
