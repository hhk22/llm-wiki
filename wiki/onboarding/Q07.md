# 온보딩 FAQ Q07 배포할 때 E-021이 뜨면 어떻게 하나요?

배포 시 E-021 에러가 발생하면 저장소 워크플로에 deployments: write 권한이 있는지 확인한다. [1] [2]

## E-021 에러 조치

- 배포 시 E-021 에러가 발생한 경우 워크플로 권한 부족을 의미한다. [1]
- 관련된 참고 문서로는 에러 코드 E-021과 장애 리포트 #12가 있다. [2]

## 관련 장애 종합

- 장애 리포트 #12에 따르면 order-api 서비스에서 GitHub Actions 전환 후 배포가 중간에 실패하여 절반의 Pod만 새 버전이었던 증상이 발생했다. [3] [4]
- 장애 리포트 #12의 원인은 워크플로에 배포 권한이 없었던 것이며 에러 코드 E-021에 해당한다. [5]
- 장애 리포트 #12의 조치로 권한을 추가하고 배포를 다시 실행하였으며 후속 조치로 배포 가이드 v15에 반영되었다. [6] [7]
