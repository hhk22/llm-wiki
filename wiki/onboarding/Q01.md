# 온보딩 FAQ Q01 프로덕션 배포는 어떻게 하나요?

프로덕션 배포는 GitHub Actions를 통해 실행하며 사전 승인과 staging 배포가 필요하다. [1] [2]

## 배포 방법

- 프로덕션 배포 시 `deploy run --env prod --ticket <id>` 명령을 GitHub Actions에서 수행한다. [1]
- 본 배포 전 staging 배포 및 승인이 선행되어야 한다. [1]

## 참조 문서

- 상세 내용은 배포 가이드 v30을 따른다. [2]
